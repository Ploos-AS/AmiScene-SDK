# M1 — AmiTable + AmiBitplane

M1 establishes the first ASM-first asset generators.

## AmiTable
Deterministic sine/cosine lookup tables with configurable size/amplitude, `dc.b/dc.w/dc.l`, alignment, labels and size symbols.

## AmiBitplane / image pipeline
The dependency-free core handles Amiga planar data. PNG input optionally uses Pillow; classic IFF ILBM input is parsed without external dependencies.

Current capabilities:
- PNG quantization to requested 1–8 plane depth
- locked palette files and opt-in dithering
- ILBM BMHD/CMAP/BODY input
- uncompressed and ByteRun1-compressed ILBM
- ILBM mask-plane stripping
- raw binary suitable for `incbin`
- generated ASM include with dimensions, depth and OCS-style 12-bit palette

Examples:

```sh
amiscene image logo.png --planes 4 --palette logo.pal --output logo.bin --asm logo.i --label Logo
amiscene image oldschool.iff --output oldschool.bin --asm oldschool.i --label Oldschool
```

ILBM BODY data is preserved in its native scanline/plane organization (minus an optional mask plane), making classic Amiga artwork a first-class source rather than forcing it through RGB conversion.
