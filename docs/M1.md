# M1 — AmiTable + AmiBitplane

M1 establishes the first ASM-first asset generators.

## AmiTable
Deterministic sine/cosine lookup tables, configurable size/amplitude, `dc.b/dc.w/dc.l`, alignment, labels and size symbols.

## AmiBitplane / image pipeline
The dependency-free core converts indexed pixels to Amiga planar data. The host PNG front-end optionally uses Pillow to quantize RGB PNG input to the requested plane depth.

Current output:
- 1–8 planar bitplanes
- separate or interleaved layout
- raw binary suitable for `incbin`
- generated ASM include with labels, size, width, height and plane count
- OCS-style 12-bit RGB palette words emitted as `dc.w`

Example:

```sh
amiscene image logo.png --planes 4 --layout interleaved --output logo.bin --asm logo.i --label Logo
```

The generated include references the raw binary rather than embedding large assets as source. This keeps normal scene assembly workflows fast and explicit.

Next M1 work includes stronger palette control, deterministic quantization tests and ILBM input/output.
