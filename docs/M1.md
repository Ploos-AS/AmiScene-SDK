# M1 — AmiTable + AmiBitplane

M1 introduces the first functional host-side primitives.

AmiTable initially generates deterministic sine/cosine lookup tables with configurable entry count and amplitude and can emit 68k assembler word tables.

AmiBitplane initially converts indexed pixel arrays to Amiga planar data, validates dimensions/depth, uses Amiga MSB-first bit ordering, and supports plane-interleaved output.

Image decoding, palette optimization, ILBM and HAM/EHB are later M1 increments. The M1 core requires no proprietary ROM or AmigaOS content.
