# M2 — AmiCopper

AmiCopper starts as an ASM-oriented Copper list builder and validator, not a visual abstraction layer.

Initial M2 core supports:
- OCS custom-register name validation
- raw even custom-register addresses
- Copper MOVE
- Copper WAIT with masks
- Copper SKIP with masks
- canonical end marker `$ffff,$fffe`
- readable `dc.w` output with comments, labels and size symbol

The host representation intentionally stays close to the hardware encoding so a scene coder can inspect every generated Copper instruction.

Next: text source format/parser, fuller OCS register map, PAL raster validation and Copper-list diagnostics.
