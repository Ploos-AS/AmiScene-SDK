# M2 — AmiCopper

AmiCopper is an ASM-oriented Copper authoring, validation and runtime layer, not a generic graphics abstraction.

## Host side

- OCS custom-register names plus raw even custom-register addresses
- MOVE, WAIT, SKIP and canonical END
- hardware-manual WAIT/SKIP encoding: IR2 bit 15 is BFD; default BFD=1 (`$8000`) so beam comparison does not wait for the Blitter
- optional `bfd=False` makes WAIT/SKIP additionally require Blitter-finished
- readable `dc.w` output
- `.copper` source parser
- CLI generation and `--check`
- errors vs scene-oriented warnings
- diagnostics for backwards WAIT, masks, unreachable commands and sensitive DMA/interrupt writes

## 68000 runtime

The OCS runtime deliberately keeps operations separable:

- `AmiCopperInstall` writes COP1LC without changing DMA
- `AmiCopperStart` strobes COPJMP1 and enables master+Copper DMA
- `AmiCopperStop` disables Copper DMA without globally disabling master DMA
- `AmiDmaSave` reads the DMA enable state
- `AmiDmaRestore` restores saved writable DMA enable bits

Every routine documents inputs and clobbers. Copper lists must be in Chip RAM. The runtime has no AmigaOS dependency and does not hide ownership/takeover policy from the coder.

## Qualification boundary

Host encoding/parser behavior is unit-testable in CI. Correct raster timing and takeover/restore behavior must additionally be qualified in the A500/OCS emulator profile and ultimately on physical hardware.
